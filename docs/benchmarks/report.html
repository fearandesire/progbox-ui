v4.1 vs v4.3 — is the new script actually better?

Head-to-head on the same export, same seed, same run count — only the progression script changed. Verified, not eyeballed: a shared scorecard, a defender spot-check, and a pass/fail gate against seven pre-agreed targets.

● Verdict — adopt v4.3

v4.3 fixes the two things that mattered: it stops the league-wide OVR deflation and it stops burying defenders. Talent still separates at equal OVR, the age curve is healthy, and the ceiling stays controlled. The one real cost is a bit more run-to-run noise — still 94% driven by player identity.

Sample-independent — they don't depend on threshold choices or the roster's age shape.

The one honest caveat

v4.3 trades a slice of determinism for its noise knob

ICC 0.984 → 0.940, Kendall W 0.980 → 0.933. Still strongly identity-dominated (94% of outcome is who the player is), but deliberately noisier — a per-player common-shock that makes breakouts and busts possible. Your call to make: is 94% acceptable? If you want it tighter, ask Ash to lower commonNoise / noiseAmp in the v4.3 config.
